
# 🎯 Project Title: Dimensionality Reduction and Classifier Performance Comparison using PCA & LDA on the Sklearn Digits Dataset

# 🚀 Project Overview:
As part of my hands-on learning journey with Intellipaat, I completed an exciting project that focused on enhancing model performance using dimensionality reduction techniques. The project involved the Digits dataset from Scikit-learn, which contains images of handwritten digits — a perfect playground for testing classification models.

# 🔍 Key Steps Undertaken:

 - Data Preprocessing: Cleaned and prepared the digit image data for modeling.

 - PCA (Principal Component Analysis):

 - Applied PCA to reduce dimensionality while preserving variance.

# Transformed data was then used to train and evaluate three classifiers:
✅ Logistic Regression
✅ Decision Tree
✅ Random Forest

Compared accuracy scores and performance metrics.

# LDA (Linear Discriminant Analysis):

Performed supervised dimensionality reduction using LDA.

Repeated classification using the same three models.

Conducted comparative analysis to evaluate how LDA impacts classifier performance relative to PCA.

# 📊 Outcome & Insights:

Observed how each classifier responded to PCA vs. LDA transformed data.

Gained valuable insights into when to use PCA (unsupervised) and LDA (supervised) based on data characteristics and project goals.

Strengthened practical understanding of dimensionality reduction and its effect on classification performance.

# 🛠️ Tools & Technologies Used:

Python, Scikit-learn, Pandas, Matplotlib, Seaborn

Algorithms: PCA, LDA, Logistic Regression, Decision Tree, Random Forest

# 📚 Learning Outcome:
This project not only improved my theoretical grasp of PCA and LDA but also enhanced my practical ability to evaluate and tune classification models in real-world scenarios.
